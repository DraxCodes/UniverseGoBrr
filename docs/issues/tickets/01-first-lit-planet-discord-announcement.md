# 01 — Discord announcement for the first lit planet

**Type:** task
**Status:** open
**Blocked by:** Layer 2 (one procedural star system) reaching a state worth looking at

## Trigger

Not before there is a single star system that looks genuinely beautiful — a lit planet with a
moving terminator, an atmosphere rim, and a camera that reads as "standing in space". Nothing
goes to the friend until a screenshot makes someone stop scrolling.

## Deliverable

1. **Screenshots, from the capture harness** (so they are reproducible, not hand-timed):
   - one wide establishing shot, 16:9, the whole system with the star in frame;
   - one close shot of the best planet, terminator visible;
   - optionally one shot at a second width, for phone viewing.
2. **A short Discord message** — 3–5 sentences, no marketing register. Must include:
   - what it is in one line ("a procedurally generated universe you can fly around, no
     gameplay, just looking");
   - that it runs in a browser from a URL, no install;
   - the coordinate string (`version/address/epoch`) for the planet in the screenshots, so
     they can go to the *same* place and the same moment;
   - one honest sentence about what does not exist yet (no landing, no gameplay systems).
3. **A second, shorter variant** (~2 sentences) for the case where the first is too long for
   the channel's tone.

## Notes

- Do not overclaim scale. At this point the universe is one system; say so.
- The coordinate is the hook. The message should make clear that the same string gets the
  same planet, for anyone, on any machine.
- Hold the "10-star artificial system" and "Dyson sphere" concepts for a later message —
  they are not built yet, and promising them now costs credibility.
- If the URL is not yet shareable (no hosting), skip the link and say "screenshots for now".
